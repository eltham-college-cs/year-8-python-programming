## The big idea

If you catch yourself writing `score1`, `score2`, `score3`… you want a **list**: one variable that stores several values, in order.

```python
scores = [12, 19, 7, 25, 16]
```

Square brackets start and end the list, with a comma between each item. Text items need speech marks: `["Ava", "Ben"]`. An empty list is just `[]`.

Each item has an **index**: its position number. Computers count from **0**.

<MemoryBoxes list={{ name: "scores", items: ["12", "19", "7", "25", "16"] }} caption="Five items, so the last index is 4, not 5." />

```python
print(scores[0])   # 12
print(scores[2])   # 7
print(scores[4])   # 16
print(len(scores)) # 5
```
